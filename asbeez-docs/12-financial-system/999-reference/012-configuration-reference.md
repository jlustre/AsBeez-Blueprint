## Purpose

This reference summarizes configuration categories. The configuration and administration folders govern exact values, ownership, scope, precedence, approval, and versioning.

## Categories

Global/country; currency/rounding; ledger/wallet; payment/payout; invoice/refund/chargeback; fee/tax/reserve; reconciliation/period close/reporting; risk/AI; feature flags; configuration versioning.

## Common Rules

Every setting is typed, owned, scoped, effective-dated, versioned, tested, approved, monitored, auditable, and reversible through a new version. Configuration cannot rewrite historical journals/events/tax/FX/reports or bypass authorization, reconciliation, security, compliance, or recovery.
