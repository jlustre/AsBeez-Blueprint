# Country Examples

> **Document:** 12-financial-system/999-reference/013-country-examples.md

---

## Purpose

These examples illustrate how country/entity scope changes financial implementation. They are patterns, not legal advice or production policy.

## Example A: New Country Pilot

Create/verify entity and registrations; configure currency/tax/calendar; approve banks/providers; set wallet/payout/reserve/risk limits; validate KYC/AML/sanctions/privacy; map chart/accounts; test payment/refund/tax/settlement; reconcile opening and pilot activity; certify support, close, incident, and DR readiness.

## Example B: Cross-Border Transaction

Retain transaction and settlement currencies; apply approved tax/entity/FX policy; preserve source/target amounts, rate, fees, rounding, and gain/loss; route through authorized provider; map local/intercompany effects; reconcile both countries; consolidate without erasing local statutory records.

## Example C: Country Incident

Scope affected entity/provider/data; pause or queue safely; preserve evidence; assess tax/liquidity/customer impact; recover; reconcile; obtain local/regulatory review; communicate; document remediation.
