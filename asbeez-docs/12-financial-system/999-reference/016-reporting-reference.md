# Reporting Reference

> **Document:** 12-financial-system/999-reference/016-reporting-reference.md

---

## Purpose

This reference summarizes financial reporting concepts; the reporting domain governs exact report definitions, datasets, certification, and delivery.

## Report Families

Trial balance, balance sheet, income statement, cash flow, GL activity, wallet/member, vendor, partner, tax, reserve, payment, payout, refund/dispute, country, consolidated, management, regulatory, budget/forecast, and reconciliation reports.

## Required Lineage

Report type/basis, source journals/snapshots, query/schema/mapping version, entity/country/currency/period, FX/tax basis, filters, dimensions, rounding, freshness, actual/estimate/projection status, certification, owner, and export/delivery evidence.

## Rules

Reports cannot mutate accounting or present estimates/provider evidence as posted certified actuals. Stale, incomplete, uncertified, or unresolved-exception data is labeled.
