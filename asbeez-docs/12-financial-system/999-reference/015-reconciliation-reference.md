# Reconciliation Reference

> **Document:** 12-financial-system/999-reference/015-reconciliation-reference.md

---

## Purpose

Reconciliation compares authoritative and evidence sources to identify, resolve, approve, and certify differences. The reconciliation domain is authoritative for exact workflows.

## Reference Flow

Define scope -> capture source snapshots -> validate completeness/period/entity/country/currency -> match by approved keys/timing/tolerance -> classify differences -> assign owner -> propose/approve resolution -> re-reconcile -> certify or reopen.

## Sources

General Ledger, subledgers, bank/provider settlements, wallets, rewards, vendors, partners, tax, reserves, country books, reports, and warehouse/control snapshots.

## Rules

Differences are visible exceptions, not balance-edit opportunities. Certification records sources, versions, totals, matched/unmatched amounts/counts, reviewer, unresolved risk, and evidence. Adjustments are approved, idempotent, ledger-linked, and followed by reconciliation.
