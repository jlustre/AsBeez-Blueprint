# Control Framework

> **Document:** 12-financial-system/270-audit-and-internal-controls/004-control-framework.md

---

## Purpose

The control framework maps financial risks to objectives, control activities, owners, evidence, testing, deficiencies, remediation, and reporting.

## Control Lifecycle

```text
Risk -> Objective -> Control Design -> Operation -> Evidence
-> Test -> Finding/Effective -> Remediation -> Retest -> Certification
```

## Control Domains

Accounting/GL, payments, wallets, payouts, refunds, disputes, rewards, vendors, partners, tax, treasury, FX, reserves, reconciliation, close, reporting, access, changes, data, AML/KYC, sanctions, privacy, and country compliance.

## Rules

Each control defines purpose, risk, owner, frequency, trigger, procedure, evidence, exception, testing, threshold, escalation, and version. Control operation does not authorize bypasses of domain policy.
