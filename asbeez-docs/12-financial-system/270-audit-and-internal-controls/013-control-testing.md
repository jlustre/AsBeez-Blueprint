# Control Testing

> **Document:** 12-financial-system/270-audit-and-internal-controls/013-control-testing.md

---

## Purpose

Control testing assesses design effectiveness, operating effectiveness, coverage, reliability, evidence, exceptions, and remediation for financial controls.

## Testing Methods

Inspection, observation, inquiry, reperformance, sampling, automated test, access review, configuration review, data analysis, reconciliation review, and end-to-end trace.

## Required Result

Control, risk/objective, period, population/sample, tester, method, evidence, result, deficiency, severity, owner, remediation, retest, approval, and conclusion.

## Rules

Testing cannot modify the tested source or hide a failure. Material failures affect close, reporting, risk acceptance, remediation, and audit communication.
