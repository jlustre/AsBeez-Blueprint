# Wallet Liability Report

> **Document:** 12-financial-system/230-financial-reporting/009-wallet-liability-report.md

---

## Purpose

The Wallet Liability Report presents approved monetary obligations represented by member/customer wallets, separated from non-monetary RP, ABC, AHC, pending, held, reserved, restricted, and disputed values.

## Required Detail

Wallet type, owner class, monetary status, currency, country/entity, ledger-backed balance, pending/held/reserved/restricted, available, source subledger, GL account, reconciliation, and policy classification.

## Rules

Wallet display balance is not automatically a liability or cash. RP, ABC, and AHC quantities are reported separately unless approved conversion creates a monetary obligation. Report distinguishes recognized, pending, payable, paid, reversed, and exception amounts.
