# Partner Commission Report

> **Document:** 12-financial-system/230-financial-reporting/012-partner-commission-report.md

---

## Purpose

The Partner Commission Report presents qualified source activity, attribution, commissions, bonuses, incentives, fees, tax, reserves, holds, settlement, payouts, and exceptions.

## Rules

Registration, referral, genealogy, or participant count is not payable evidence. Report distinguishes estimated, qualified, approved, payable, paid, held, reversed, disputed, and exception values and states program, country, entity, currency, funding, and reconciliation status.

## Certification

The report retains source activity, attribution, program version, commission/bonus/incentive calculation, funding, settlement, payout, tax, exception, reconciliation, and approval references.
