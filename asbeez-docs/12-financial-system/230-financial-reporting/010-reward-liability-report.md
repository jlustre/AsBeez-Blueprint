# Reward Liability Report

> **Document:** 12-financial-system/230-financial-reporting/010-reward-liability-report.md

---

## Purpose

The Reward Liability Report presents approved monetary obligations arising from classified RP, ABC, AHC, referral, compensation, redemption, or loyalty events, separately from program quantities.

## Required Detail

Reward type/event, member/program/country/entity/currency, qualifying source, recognized liability, expense, reserve, released, redeemed, reversed, expired, forfeited, outstanding, wallet/payout effect, policy, account mapping, and reconciliation status.

## Rules

RP, ABC, AHC, matrix placement, or referral activity is not a liability by default. Report distinguishes program-only, pending classification, recognized, held, payable, paid, reversed, and exception values.
