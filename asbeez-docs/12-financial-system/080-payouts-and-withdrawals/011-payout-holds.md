# Payout Holds

> **Document:** 12-financial-system/080-payouts-and-withdrawals/011-payout-holds.md

---

## Purpose

A payout hold prevents submission or completion while a defined risk, compliance, reserve, dispute, fraud, destination, tax, or operational condition is reviewed.

## Hold Data

Hold ID, payout/request, amount, currency, reason, source case, owner, scope, created time, review/expiry, release condition, policy version, and release decision.

## Rules

Held value remains attributable to its wallet, settlement, vendor, partner, member, or reward source. A hold does not create a debit, release a liability, or authorize confiscation. Release requires evidence and revalidation; releasing a hold does not guarantee provider payment.
