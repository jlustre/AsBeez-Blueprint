# Return Accounting

> **Document:** 12-financial-system/130-refunds-returns-and-cancellations/007-return-accounting.md

---

## Purpose

Return accounting records the financial consequences of a returned physical product, digital product, service, subscription, or other order item after return eligibility and condition are determined.

## Required Detail

Return ID, order/line, vendor, customer, fulfillment/delivery, condition, reason, received date, refund amount, tax, shipping/fees, vendor/partner adjustment, reserve, reward effect, inventory/service treatment, and GL/subledger references.

## Rules

Return acceptance is not automatically refund completion. A return may trigger full/partial refund, replacement, credit, restocking fee, vendor adjustment, tax correction, reward reversal, or no financial effect according to policy. Original sale and fulfillment history remains immutable.
