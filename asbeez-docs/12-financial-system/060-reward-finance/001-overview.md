# Overview

> **Document:** 12-financial-system/060-reward-finance/001-overview.md

---

## Purpose

Reward Finance records and governs the financial consequences of AsBeez marketplace rewards. It does not decide product eligibility, RP earning rules, ABC generation, genealogy, matrix placement, or AHC distribution; those domains publish events and policy versions for financial evaluation.

## AsBeez Reward Chain

```text
Qualifying marketplace activity
	-> RP event
	-> ABC eligibility/creation event
	-> matrix placement/distribution event
	-> AHC event
	-> approved monetary classification, if any
	-> liability, expense, redemption, wallet, settlement, or no monetary effect
```

## Principles

- RP, ABC, and AHC are not money by default.
- Monetary recognition requires approved Legal, Finance, country, funding, and accounting policy.
- Every financial effect references the source reward, order, member, country, program, and rule versions.
- Refunds, chargebacks, fraud, and expiry propagate through explicit correction events.
- Reward liabilities are measured, funded, capped, reconciled, and reported separately from program quantities.
