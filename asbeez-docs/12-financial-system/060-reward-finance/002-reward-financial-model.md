# Reward Financial Model

> **Document:** 12-financial-system/060-reward-finance/002-reward-financial-model.md

---

## Purpose

The Reward Financial Model distinguishes AsBeez reward program activity from monetary accounting and defines when an event creates an obligation, expense, redemption, wallet credit, or no financial effect.

## Layers

| Layer | Owner | Financial meaning |
| --- | --- | --- |
| Marketplace activity | Marketplace/Commerce | source transaction and qualifying status |
| RP | Rewards | non-money quantity and qualification history |
| ABC | Rewards | platform participation record |
| Matrix | Beehive Matrix | placement, genealogy, cycle, distribution facts |
| AHC | Rewards/Matrix | non-money reward quantity and event history |
| Reward Finance | Financial System | approved financial classification, measurement, and mapping |
| Wallet/Payout | Wallets/Payouts | controlled monetary availability and execution |

## Recognition Decision

For every event, Reward Finance evaluates jurisdiction, legal classification, funding source, program terms, qualifying source, liability ceiling, reversibility, and accounting policy. Possible outcomes are non-monetary record only, pending financial review, reward liability, reward expense, redemption liability, wallet credit, settlement obligation, or rejected/reversed effect.

## Prohibited Assumptions

ABC creation is not company ownership. AHC is not currency. Matrix placement is not a payment. A member display balance is not a payable. No reward amount is presented as guaranteed income without approved disclosure and classification.
