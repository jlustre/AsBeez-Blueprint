# Report Generation

> **Document:** 12-financial-system/330-ai-capabilities/016-report-generation.md

---

## Purpose

AI assists report generation by drafting narratives, selecting approved metrics, explaining variances, formatting management views, and preparing report requests from authorized datasets.

## Output

Reports identify source records/snapshots, query and schema version, actual/projection/forecast basis, period, entity/country/currency/FX basis, filters, rounding, freshness, assumptions, uncertainty, exclusions, and certification status.

## Controls

AI cannot alter source data, create unsupported figures, certify financial/regulatory reports, change accounting policy, select unauthorized populations, or conceal exceptions. Certified outputs require authorized human review and preserve generated content, source lineage, and approval evidence.
