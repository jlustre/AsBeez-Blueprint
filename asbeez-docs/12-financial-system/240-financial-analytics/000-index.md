## Design Authority

Financial Analytics owns derived metrics, KPI definitions, dashboards, forecasts, anomaly signals, snapshots, and insight models. Financial Reporting owns certified reports; Reconciliation, Ledger, Subledgers, Treasury, Revenue, Tax, Reserves, Rewards, Vendor/Partner Finance, and Payments provide authoritative sources.

## Implementation Sequence

1. Approve metric definitions, sources, grains, dimensions, periods, entities, countries, currencies, and data governance.
2. Implement KPI, revenue, profitability, cash, wallet, reward, vendor/partner, country, payment, refund, dispute, tax, forecast, and anomaly analytics.
3. Implement dashboards, snapshots, API, events, exports, access, certification references, and audit.
4. Connect reporting, reconciliation, budgeting, treasury, reserves, settlements, rewards, and close; then add governed AI.
