# Referral Commissions

> **Document:** 12-financial-system/150-fees-and-commissions/013-referral-commissions.md

---

## Purpose

Referral commissions are approved obligations tied to qualifying AsBeez commerce or an explicitly approved referral service, with attribution and program evidence.

## Rules

Referral registration, invitation, recruitment, genealogy, or participant count alone does not create commission. The program must require genuine qualifying activity, define the funding source, cap, return period, fraud/chargeback response, tax, disclosure, country, and payout conditions.

## Required Detail

Referrer/beneficiary, referred customer/member where permitted, order/service, attribution, qualification, basis, rate/fixed amount, currency, reserve/hold, tax, approval, settlement, payout, and reversal.
