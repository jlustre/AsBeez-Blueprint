# Incident Response

> **Document:** 12-financial-system/280-security/017-incident-response.md

---

## Purpose

Incident response contains, investigates, communicates, recovers, and learns from security, fraud, privacy, provider, data, availability, and financial-integrity incidents.

## Lifecycle

```text
Detected -> Triage -> Contained -> Investigated -> Eradicated
-> Recovered -> Notified/Reported -> Reviewed -> Closed
```

## Rules

Incident response preserves evidence and immutable financial history, protects customers/partners/vendors, invokes Legal/Compliance/Finance/Risk/Operations as required, and records scope, timeline, decisions, impact, notifications, recovery, root cause, and corrective action. Emergency locks, credential rotation, payout holds, or provider isolation require later review.
