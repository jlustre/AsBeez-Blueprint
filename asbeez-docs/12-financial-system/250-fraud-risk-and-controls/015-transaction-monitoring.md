# Transaction Monitoring

> **Document:** 12-financial-system/250-fraud-risk-and-controls/015-transaction-monitoring.md

---

## Purpose

Transaction monitoring observes financial and program activity for unusual, prohibited, unauthorized, or high-exposure patterns across orders, payments, wallets, refunds, payouts, rewards, vendor/partner settlement, tax, reserves, and treasury.

## Monitoring Contract

Event/source, subject, amount/unit/currency, entity/country, time, rule/model version, signal, score/confidence, decision, owner, case, action, appeal, and resolution.

## Rules

Monitoring is proportionate, privacy-aware, and continuously tested for drift and false positives. Alerts do not alter source or ledger records; action follows authorized control workflow and retains customer/participant rights.
