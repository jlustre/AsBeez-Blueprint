# Variance Analysis

> **Document:** 12-financial-system/200-budgeting-and-forecasting/012-variance-analysis.md

---

## Purpose

Variance analysis explains differences between budget, prior forecast, current forecast, actual reconciled results, commitments, and approved scenarios.

## Variance Types

Volume, price/rate, mix, timing, FX, scope, country, entity, vendor/partner, reward, tax, reserve, provider, refund/chargeback, and classification variance.

## Rules

Actuals derive from reconciled ledger/subledger/reporting data. Each material variance has owner, threshold, reason, evidence, action, due date, and status. Variance does not justify editing actuals or bypassing budget/approval controls.

## Reporting

Variance reports distinguish favorable/unfavorable, plan/forecast/actual basis, currency, entity, country, period, driver, materiality threshold, owner, action status, and approval history.
