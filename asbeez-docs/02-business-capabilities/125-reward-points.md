# Overview

Reward Points (RP) are loyalty points earned by Members from eligible purchases made through the AsBeez Marketplace.

Reward Points encourage Members to remain loyal customers by recognizing their purchasing activity.

Reward Points are accumulated until they reach the required threshold to create an AsBeez Business Cell (ABC).

---

# Responsibilities

The Reward Points capability is responsible for:

- Calculating Reward Points
- Recording Reward Point transactions
- Maintaining Reward Point balances
- Tracking Reward Point history
- Determining when RP thresholds are reached
- Publishing Reward Point events

The Reward Points capability is **not responsible** for:

- ABC creation
- AHC distribution
- Wallet credits
- Referral qualification
- Refund processing

---

# Reward Point Calculation

Reward Points are calculated from the AsBeez Revenue Share generated by an eligible purchase.

General Formula:

```text
Net Product Amount

↓

Vendor Revenue Share

↓

Member Reward Allocation

↓

Reward Points (RP)
```

The calculation formula is configurable.

---

# Reward Point Information

Each Reward Point transaction records:

- Transaction ID
- Member ID
- Order Number
- Source Transaction
- RP Earned
- RP Adjusted
- Transaction Date
- Status

---

# Reward Point Balance

Each Member maintains:

- Available RP
- Pending RP
- Total Lifetime RP

Only Available RP is used when determining eligibility for ABC creation.

---

# RP Threshold

When a Member's Available RP reaches the configured threshold, the Reward Points capability publishes an event indicating that an ABC may be created.

The default threshold is:

```text
120 RP
```

Unused Reward Points remain in the Member's balance.

Example:

```text
Current RP = 250

ABC Threshold = 120

ABC Created = 2

Remaining RP = 10
```

The actual creation of an ABC is performed by the **ABC Engine**.

# Reward Point Workflow

```text
Eligible Purchase
        │
        ▼

        ▼

        │

```

---

# Business Rules

| Rule ID | Description |
|----------|-------------|
| BR-RP-001 | Only eligible purchases generate Reward Points. |
| BR-RP-002 | RP are calculated from the configured revenue-sharing formula. |
| BR-RP-003 | Reward Points accumulate until the configured threshold is reached. |
| BR-RP-004 | Remaining RP are retained after an ABC threshold is met. |
| BR-RP-005 | Multiple ABC thresholds may be reached from a single transaction. |
| BR-RP-006 | RP adjustments are performed by the Reward Adjustment capability. |
| BR-RP-007 | RP do not expire while the Member account remains active. |
