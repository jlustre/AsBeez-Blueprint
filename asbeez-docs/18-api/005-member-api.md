# Member API

## Purpose

The Member API supports registration/profile, membership status, country assignment and approved migration, referrals, loyalty activity, RP/ABC/AHC views, wallet views, orders, support, and eligible requests.

## Scope

Responses are limited by member identity, role, country, consent, resource ownership, privacy, policy, and lifecycle state. Country assignment is platform state subject to residency, tax, privacy, sanctions, and legal review; it is not proof of legal or tax residence.

## Rules

Members see reward units separately from monetary wallet balances and receive clear eligibility, reversal, expiry, conversion, and payout conditions. Referral and reward APIs cannot promise income, passive returns, ownership, appreciation, or guaranteed withdrawal. Commands are authenticated, authorized, idempotent, auditable, and reviewable.
