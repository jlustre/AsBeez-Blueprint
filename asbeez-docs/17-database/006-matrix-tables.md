# Matrix Tables

## Purpose

Matrix tables record Beehive Matrix structures, placements, cells, relationships, qualification inputs, country context, and historical placement without becoming a financial ledger.

## Table Groups

`matrices`, `matrix_versions`, `matrix_cells`, `matrix_positions`, `matrix_members`, `placement_events`, `qualification_snapshots`, `matrix_distributions`, and placement audit references.

## Rules

Matrix placement and reward qualification are owned by the Matrix/Rewards contexts. Tables retain source member, event, policy/version, country, timestamp, and immutable placement history. Cross-country behavior follows approved platform and country policy; existing historical placement is not silently moved.

## Financial Boundary

Matrix records do not represent money, equity, ownership, revenue, or guaranteed income. Any approved reward liability, expense, reserve, conversion, or payout is created by Reward Finance and the financial system through explicit source and accounting references.
