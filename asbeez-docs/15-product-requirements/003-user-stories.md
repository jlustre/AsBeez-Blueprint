﻿# User Stories

## Purpose

These representative user stories express product outcomes and boundaries. Each story requires a domain owner, acceptance criteria, policy/version, scope, source, audit, and test evidence before release.

## Commerce and Marketplace

- As a customer, I want to discover and purchase an approved product so that I receive a clear order, payment, tax, and fulfillment status.
- As a vendor, I want to publish approved products and view earnings so that I can operate my storefront with transparent fees, tax, reserves, settlement, and payout status.
- As a support operator, I want to investigate an order using authorized evidence so that I can resolve customer/vendor questions without changing financial truth.

## Loyalty and Participation

- As a member, I want to see qualifying activity and RP/ABC/AHC separately so that I understand program status without mistaking units for money.
- As a member, I want clear reward eligibility, reversal, expiry, and payout conditions so that participation is informed and voluntary.
- As a compliance reviewer, I want reward and referral claims reviewed by country so that prohibited income or recruitment claims are blocked.

## Financial Operations

- As a finance operator, I want to review balanced journal requests so that only approved effects post to the General Ledger.
- As a reconciliation owner, I want differences assigned with evidence and aging so that unresolved control breaks are visible and actionable.
- As a treasury operator, I want reconciled cash and obligations so that transfers and liquidity decisions are controlled.

## Safety and Governance

- As an authorized user, I want idempotent payment, refund, payout, and wallet commands so that retries do not duplicate effects.
- As an auditor, I want source, policy, actor, approval, and correction lineage so that decisions are reproducible.
- As a user, I want AI explanations and recommendations with sources and uncertainty so that I can make informed decisions while retaining human accountability.
