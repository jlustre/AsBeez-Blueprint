# UI/UX

## Purpose

This domain defines AsBeez user experiences, design system, customer website, member/vendor/admin portals, and mobile behavior.

## Experience Authority

UI/UX expresses product requirements and domain/API state; it does not redefine business policy, legal terms, financial authority, or authorization. Screens use approved APIs and events, preserve scope/privacy, and make uncertainty visible.

## Global Rules

Use accessible, responsive, localized, privacy-aware, role-scoped interfaces with clear loading/error/empty/pending/unknown states. Show amount, currency, tax/fee, policy, status, source/freshness, and next action where relevant. Never imply payment, revenue, payout, reward conversion, approval, certification, or completion before authoritative state exists.
