# AI Recommendations

## Purpose

AI recommendations suggest content, products, actions, classifications, routes, priorities, controls, or workflow next steps using approved data and policy.

## Recommendation Contract

Return recommendation ID/type, candidate, rationale, evidence, model/rule/prompt version, confidence, alternatives, scope, timestamp, expiration, risk/impact, human decision, and resulting action reference.

## Rules

Recommendations are advisory unless a documented deterministic rule applies. They cannot independently deny rights, freeze/release funds, change accounting, select unrestricted mappings, approve transactions, or make final legal/compliance decisions. Material recommendations require human review, appeal where relevant, monitoring for bias/drift, and audit.
