# Prompt Library

## Purpose

The prompt library manages reusable, versioned instructions and templates for assistants, agents, search, recommendations, reporting, fraud/risk, support, operations, and financial assistance.

## Prompt Record

Prompt ID/version, owner, purpose, use case/risk tier, approved model/providers, input/output schema, data classification, tools, scope, safety rules, examples, evaluation set, metrics, approval, effective date, changelog, incident history, and retirement status.

## Rules

Prompts are tested for correctness, injection resistance, leakage, bias, hallucination, refusal, structured output, cost, latency, and regression. Prompts cannot instruct a model to bypass authorization, expose restricted data, or directly perform prohibited financial actions. Secrets and unnecessary personal data never appear in prompts.
