# Template Library

## How to Use

1. Copy the closest template into the owning domain.
2. Replace every placeholder and remove sections that do not apply.
3. Add source, authority, scope, owner, version, status, dates, links, evidence, approvals, and unresolved questions.
4. Apply privacy, security, legal, financial, country, accessibility, and retention controls.
5. Validate links, headings, claims, acceptance evidence, and revision history before publication.

## Naming

Use lowercase kebab-case filenames with stable numeric prefixes where the owning domain uses them. Do not rename a published artifact without recording the migration or supersession.
