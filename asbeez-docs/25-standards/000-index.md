# Standards

## Purpose

This domain defines shared documentation, naming, identifier, diagram, API, database, coding, security, and versioning standards for AsBeez.

## Authority

Standards provide consistency and quality constraints; domain policies, legal requirements, API/event contracts, the General Ledger, security controls, and approved ADRs govern behavior where standards intersect with authority.

## Global Rules

Use stable, explicit, versioned, traceable artifacts; preserve source/effective date/owner/status; use secure defaults; test changes; protect sensitive data; document exceptions; and never use a standard to justify direct mutation of immutable financial truth or bypass of legal/security controls.
