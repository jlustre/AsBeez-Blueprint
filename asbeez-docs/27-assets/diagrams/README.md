# Diagram Assets

## Purpose

Diagrams include architecture, context, ERD, workflows, state, sequence, event, financial, and operating-control visuals.

## Requirements

Each diagram records owner, version/date, scope, source documents, notation, legend, assumptions, status, accessibility text, and review date. Source/editable files are retained with rendered exports.

## Controls

Diagrams must distinguish commands, events, external evidence, projections, ledger authority, human approval, failure, and unknown states. Review diagrams when architecture, contracts, data, policy, or ADRs change.
