# Brand Assets

## Purpose

Brand assets include logos, marks, color palettes, typography references, icons, brand guidelines, social templates, and approved visual identity files.

## Requirements

Record asset ID, name, type, format, dimensions, variant, background, color profile, owner, source, license/rights, approved use, country/channel restrictions, version, status, and review date. Preserve master and derivative files separately.

## Controls

Use only approved marks and current brand guidance. Do not alter proportions, imply endorsement, or publish unapproved financial/income/reward claims in branded creative.
