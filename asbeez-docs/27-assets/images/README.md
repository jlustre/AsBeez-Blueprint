# Image Assets

## Purpose

Images include product photography, marketplace imagery, editorial content, illustrations, campaign media, and approved stock or generated visuals.

## Requirements

Record asset ID, source/creator, license or consent, usage scope, model/property release where applicable, alt text, dimensions, crop variants, accessibility, privacy classification, and expiration/review date.

## Controls

Do not use unlicensed, misleading, private, or sensitive imagery. AI-generated images require provenance, review, disclosure where appropriate, and confirmation that no protected or personal material is improperly reproduced.
