# Screenshot Assets

## Purpose

Screenshots capture approved product, support, operational, financial, API, and administrative states for documentation, testing, training, and communication.

## Requirements

Record environment, version, date, role, country/entity, data classification, source workflow, redaction status, consent/authorization, owner, and usage scope.

## Controls

Use synthetic or masked data. Never expose secrets, credentials, full payment details, private identity evidence, unrestricted risk/compliance data, or production records without approved purpose and controls.
