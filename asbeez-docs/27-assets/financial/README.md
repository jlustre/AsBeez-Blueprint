# Financial Assets

## Purpose

Financial assets include approved charts, report visuals, model exhibits, KPI graphics, waterfall charts, unit-economics visuals, forecasts, and investor-ready financial exhibits.

## Requirements

Every asset identifies period, entity/country, currency/FX basis, source/report version, actual versus estimate/forecast, methodology, exclusions, owner, approval, confidentiality, and review date.

## Controls

Do not present GMV as revenue, estimates as actuals, reserves as free cash, rewards as money, or projections as guarantees. Finance and Legal approve material external use.
