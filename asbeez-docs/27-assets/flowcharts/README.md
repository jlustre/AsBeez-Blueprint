# Flowchart Assets

## Purpose

Flowcharts show user journeys, financial workflows, approvals, operations, escalation, reconciliation, close, incident, and recovery procedures.

## Requirements

Record trigger, actor, scope, states, decision rules, exceptions, failure/unknown paths, owner, source/runbook, version, and review date.

## Controls

Flowcharts cannot imply that a UI, provider, AI, projection, or operator can bypass authorization, reconciliation, legal, security, or ledger controls.
