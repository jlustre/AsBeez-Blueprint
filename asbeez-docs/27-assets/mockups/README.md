# Mockup Assets

## Purpose

Mockups represent proposed product, portal, admin, dashboard, checkout, wallet, reward, reporting, and operational experiences.

## Requirements

Record target role, workflow, viewport, state, source requirements, API/data assumptions, accessibility, privacy, status, version, owner, and linked acceptance criteria.

## Controls

Mockups are not authoritative behavior until accepted into product requirements and APIs. Financial values, rewards, approvals, and statuses must be labeled as illustrative unless sourced from an approved contract.
