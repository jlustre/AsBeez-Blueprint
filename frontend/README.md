# AsBeez Frontend

The React application lives here. The Laravel backend is a sibling directory at `../backend`.

## Development

From `C:\JCL_Files\projects\AsBeez\frontend`:

```powershell
npm install
npm run dev
```

The active entrypoint is `src/app.tsx`. React, TypeScript, Tailwind CSS, and Alpine.js are configured in this project.

## Validation

```powershell
npm run build
npm run typecheck
```
